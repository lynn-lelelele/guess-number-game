# Python 猜数字游戏

一个使用 Python 编写的命令行猜数字小游戏。程序会随机生成一个 `1～100` 的整数，玩家最多可以猜 `7` 次，并根据每次猜测给出“猜大了”“猜小了”或“猜对了”的提示。

## 项目目标

通过一个完整的小项目练习以下内容：

- 使用 `random` 生成随机数
- 使用 `while` 循环控制游戏流程
- 使用 `if / elif / else` 判断游戏结果
- 使用 `try / except` 处理非整数输入
- 使用 `break` 和 `continue` 控制循环
- 使用变量记录游戏状态
- 编写 README 和测试记录

## 功能

- 随机生成 `1～100` 之间的整数
- 每局最多允许有效猜测 `7` 次
- 提示“猜大了”“猜小了”或“猜对了”
- 非整数输入不会导致程序崩溃，也不会计入猜测次数
- 猜中后显示本局使用的猜测次数
- 7 次未猜中时公布正确答案
- 支持使用 `y / Y / n / N` 决定是否再来一局
- 重开输入不合法时自动重新询问
- 退出时输出结束语

## 运行环境

- Python 3.8 或更高版本
- 不需要安装第三方依赖

## 快速开始

进入项目目录：

```bash
cd guess-number-game
```

运行程序：

```bash
python main.py
```

Windows PowerShell 也可以使用：

```powershell
python .\main.py
```

## 游戏规则

1. 程序随机生成一个 `1～100` 的整数。
2. 输入一个整数进行猜测。
3. 程序会提示“猜大了”“猜小了”或“猜对了”。
4. 每局最多有 `7` 次有效猜测机会。
5. 输入非整数时会提示“请输入整数”，该次输入不计入次数。
6. 猜中或次数用完后，程序询问是否再来一局。
7. 输入 `y` 或 `Y` 开始新一局。
8. 输入 `n` 或 `N` 退出程序。
